Making

This site is part of the work. This is how it’s made.

Tools

I’ve been on a journey to use only free and open-source software for a while now, and whenever possible, TUI applications. I’m drawn to lightweight, frictionless software and a keyboard-driven workflow. These are the tools I use to build this site.

Setup

  • Hugo: Generates static sites. If you’re still editing pages manually, this can make your life much easier.
  • Text editor: Neovim (once you learn how it works, you’ll wish everything worked the same way).
  • File manager: vifm (same Vim logic. I never have to touch a mouse).
  • OS: Artix Linux (Arch without systemd. I kind of regret going that far.)
  • Window manager: Sway (I’ve been using tiling window managers for years now, and I can’t imagine going back to floating).
  • Terminal emulator: foot (I moved from Alacritty because this supports Sixel image viewing, which I need to preview images in the terminal with vifm).

Graphics

  • Drawing: AzPainter (this one doesn’t get enough love. It feels light and fast, and I love it. If you’re coming from PaintTool SAI2, you’ll feel right at home).
  • Sprites: LibreSprite (a FOSS fork of Aseprite).
  • Image editing: GIMP (I’m not a huge fan, but it does the job once you understand it).
  • ffmpeg and ImageMagick: command line tools for video and images. I use them to create many of the animations you see here, glued together with shell scripts.

Fonts

  • Noto Serif: Supports many glyphs across many languages. A common default/fallback serif in many systems/browsers, and using it here is intentional.
  • M PLUS 2: A Japanese font that also supports English glyphs quite well. It has that “Japanese product for international audiences” vibe. I mainly use it on Lady Thread’s Blog.
  • JetBrains Mono: A very popular monospace font. On this site, I use it for buttons and input fields. I also personally use it in my terminal emulator.
